# Cognifyz Level 2 – Restaurant Data Analysis

## Overview

This project was completed as part of the Cognifyz Technologies Data Science Internship Program. The project focuses on advanced restaurant data analysis including table booking analysis, online delivery analysis, price range analysis, and feature engineering techniques.

The project was implemented using Python in Google Colab.

---

# Objectives

The main objectives of this project are:

* Analyze table booking and online delivery services
* Perform price range analysis
* Understand customer rating patterns
* Apply feature engineering techniques
* Generate meaningful visualizations and insights

---

# Technologies Used

* Python
* Google Colab

* Matplotlib
* Seaborn
